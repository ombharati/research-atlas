# Problem Atlas

A personal research repository for exploring real-world problems, understanding where existing systems fail, and identifying meaningful opportunities for technology.

The focus is currently on **India**, particularly rural and underserved communities, with an emphasis on healthcare, public services, and AI.

The research follows:

```text
Problem → Evidence → Existing Solutions → Gap → Opportunity
```

## Structure

```text
research/       Deep research by topic
synthesis/      Cross-research findings
sources/        Important references
decisions/      Selected and rejected opportunities
experiments/    Validation, prototypes, and findings
```

Research is kept evidence-backed and dated so it can be reused for future projects, experiments, and problem discovery.
